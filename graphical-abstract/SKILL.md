# 图形摘要

Start with /input/case.json, task.md and actual materials. List the resources described in environment/resources.yaml. Work in /app/work and write final files to /app/output. Read the real paper and supplied deck or template before designing. Preserve both original evidence and requested specimen files. Inspect the original output_contract and deliver every required field plus original case_id. Write initial result.json early and update it after visual verification. Source citations identify exact PDF page and printed figure/panel, table field, slide/object, or file and line for independently uploaded data. Distinguish unreadable input, ambiguous evidence and export failure.

1. Read the paper's title, research question, one comparative result and limitations. Write the scientific takeaway in a sentence with an actual source locator. Pick a visual grammar that fits the evidence: intervention/comparator, mechanism, spatial scan, side-by-side pattern or a single central result. Restrict the story to what can be seen in one glance. Retain directional meaning and uncertainty markers. Cite the original figure or table in your source map.
2. Draft three thumbnail ideas mentally and pick the one whose visual hierarchy communicates the claim without a long caption. Use `python scripts/visual.py spec.json /app/work/render` for source-linked primitive and data scenes. For asset-intensive work use a real supplied source image, retain original labels or directly editable annotations, and create authored SVG. Follow any journal-specific orientation, target dimensions, color, background or word limit. Prefer direct labels to a legend when possible. Give the active marks contrast and use consistent colors for the same entity. Keep a readable visual path and use precise glyphs instead of generic visual motifs.
3. Verify each graphic claim, relationship, axis, unit and sample-size note against the source. Compare with any original image at a matched viewing size. Re-open editable SVG and verify text and groups, PNG dimensions and PDF render. Supply source map, editable source, exports and a short alt description. Use references/design.md. The included small-multiples scene demonstrates numerical evidence with a public teaching dataset.

Write all exact task deliverables using task-required names. Run `python scripts/finish_case.py /input/case.json actual-fields.json /app/output/result.json` only after generating cited files and actual-field values. Review nested requirements and relative paths independently. Do not use demonstration material as an answer to any provided case.
