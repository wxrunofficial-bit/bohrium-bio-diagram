# Visual brief and acceptance checks

Write a one-sentence intended reading before selecting color or geometry. Put the evidence needed to understand that reading in the main area, with accessible foreground/background contrast, direct labels, and a restrained palette. Use secondary shapes, patterns or position for meaning that color also conveys. Review the intended output at actual scale and in grayscale. Re-open the exported vector and rasterized PDF. Inspect edits against the original source. Preserve live text and editable marks, plus exact image/slide sources and hashes when they matter. Adopt a publication’s own dimensions and font instructions if given.

- K-Dense Scientific Visualization motivates encoded evidence, color semantics, export metadata and a post-render inspection. K-Dense Scientific Schematics motivates checking actual arrow targets, overlap and visible labels in a second rendering pass. No external model or script download is necessary. [Scientific Visualization](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scientific-visualization/SKILL.md) · [Scientific Schematics](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scientific-schematics/SKILL.md)
- Nature's figure specifications inform legible editable labels, careful unit and scale annotation, and comparison at final reproduction size. Its prescribed sizes and house style apply to the relevant destination. [Nature figure guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)
- Use validated SBGN glyphs when a biological task explicitly requires the formal notation. The simple scene examples borrow the distinction between activity and inhibition; SBGN conformance requires the relevant full vocabulary and checks. [SBGN visual languages](https://sbgn.github.io/specifications)

Acceptance: mark unverified data or links as unresolved. An output is reviewable when someone can identify the main comparison, recover the represented relation/data from its locator, edit individual objects, and render the same readable figure at the required scale.
