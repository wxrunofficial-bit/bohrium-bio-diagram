# Evidence-linked schematics

Only invoke for a real mechanism, schematic or workflow in the workorder. Read the supplied primary pages and captions, including arrows, spatial boundaries, molecule identifiers and sign convention. Record each assertion as (subject, relation, object, compartment, directness, evidence locator). Differentiate measurements, model assumptions and proposed connections. Preserve existing artwork when editing. When creating a new chart from biological data use the quantitative renderer and retain compound/gene/condition spellings verbatim.

scripts/graph.py exposes validate and render for de novo source-grounded diagrams. Inspect validate() for the required graph schema. An edge must resolve to two nodes and a real source, and its render style must match the evidence. Use ET.ElementTree(root).write for editable SVG and svgtools.export(svg,root,2) for rendered PNG/PDF. If the primary source implies an ambiguous spatial ordering or an unconfirmed intermediate, annotate the uncertainty. Confirm nodes and directions by inspecting the final preview against the actual source panel. Record any manually adjusted ports and positions. For a source-preserving change use local_edit.py on the supplied original.
