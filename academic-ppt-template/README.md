# 学术 PPT 模板与格式适配

Read SKILL.md for the workflow and references/design.md for design checks. Install requirements.txt under Python 3.10+ if dependencies are absent. Work from this directory. Use installed fonts containing the actual language. For Unicode-heavy plots choose a compatible font family and confirm no missing glyph at full size. Set MPLCONFIGDIR to a writable location on shared machines.

## Local demonstration

```sh
python examples/make_template.py /tmp/template-demo
python scripts/edit_deck.py inspect /tmp/template-demo/template.pptx
python scripts/edit_deck.py adapt /tmp/template-demo/template.pptx /tmp/template-demo/adapt.json /tmp/template-demo/revised.pptx
python scripts/check_deck.py /tmp/template-demo/revised.pptx /tmp/template-preview
```

The illustrative 4:3 template builds a real layout placeholder, speaker notes and fixed footer. Adaptation fills the requested objects in place with the original master, layouts, theme, canvas and notes retained. For other formats and different slide counts use native layout selection and real placeholder IDs. Native templates vary in fonts and inherited elements, so render reference and result through the same engine.

The checked demonstrations are independent of the official cases. Vector sources and previews are generated by the scripts from this folder or from the actual case inputs. Start each run in a fresh directory. The provided readback renderer covers the editable primitive subset. Use PowerPoint or LibreOffice for arbitrary imported templates, charts or Office layout verification. Check generated paths, fonts, accessibility and presentation timing against the case's exact output contract.

## Influences and decisions

| Practice | How it is used here |
|---|---|
| Penn State assertion–evidence structure | A body slide's title states a checkable claim. Plots, figures or explanatory diagrams occupy the main area. Notes retain evidence and bridges. |
| Anthropic PPTX creation and editing | Inspect real layouts and placeholder IDs before editing. Compare chosen screenshots at equal size and require a separate package/object audit. |
| K-Dense scholarly visualization and diagram review | Keep source identity and export checks together, review contrast and repeat the visual pass when a label, mark or line fails. |
| Nature and Cell Press figure guidance | Preserve legible vector marks, review thumbnail order, check presentation size and preserve issue-specific publication requirements. |

Sources and examples appear in references/design.md. Layouts, scripts and visual examples in this package were authored for this task.
